# Contributing to Settings Sidebar Organizer

Thanks for wanting to help improve the plugin! 

## How to contribute
* **Report Bugs:** Open an issue on GitHub describing the problem and how to reproduce it.
* **Feature Requests:** Feel free to open an issue to pitch your ideas.
* **Pull Requests:** If you want to submit code fixes, just fork the repository, make your changes, and open a pull request. 

Please keep code clean and stick to the existing project style. Thanks!
